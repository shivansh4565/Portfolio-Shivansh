## 🔬 DeepScope

### Multi-Agent AI Research Assistant

An AI research application that uses specialized agents to automate different stages of research.

### Architecture

```text
             User Query
                 │
                 ▼
          ┌──────────────┐
          │ Search Agent │
          └──────┬───────┘
                 │
                 ▼
          ┌──────────────┐
          │ Reader Agent │
          └──────┬───────┘
                 │
                 ▼
          ┌──────────────┐
          │ Writer Agent │
          └──────┬───────┘
                 │
                 ▼
          ┌──────────────┐
          │ Critic Agent │
          └──────┬───────┘
                 │
                 ▼
          Research Report
````

### Key Features

* Search Agent
* Reader Agent
* Writer Agent
* Critic Agent
* Multi-Agent Workflow
* Automated Research Reports

### Tech Stack

`LangGraph` `LangChain` `Tavily` `Streamlit`

# 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/shivansh4565/shivansh-portfolio.git
```

Move into the project:

```bash
cd shivansh-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```

---

# 📦 Build For Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
